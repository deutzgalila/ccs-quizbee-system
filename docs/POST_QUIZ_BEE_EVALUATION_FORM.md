## 3. 1-Click Automated Generator (Google Apps Script)

You can automatically generate the entire Google Form formatted with all sections, scales, checkboxes, and descriptions in **under 5 seconds** using Google Apps Script.

### Step-by-Step Instructions:
1. Open [Google Drive](https://drive.google.com/) or visit [script.google.com](https://script.google.com/).
2. Click **New > More > Google Apps Script** (or create a blank standalone project).
3. Delete any default code in `Code.gs`, paste the script below, and click **Save** (💾).
4. Select the function `createQuizBeeEvaluationForm` and click **Run** (▶).
5. Grant Google permissions when prompted.
6. Check the **Execution Log** at the bottom — it will output the live **Edit URL** and **Published Form URL** ready to share with contestants!

## 4. Key Metrics for ITPM 311 Project Analysis

Once responses are collected in Google Forms (and exported to Google Sheets), you can directly calculate key project performance indicators:

| Evaluation Metric | Target Indicator | ITPM 311 Report Significance |
| :--- | :--- | :--- |
| **System Usability Scale (SUS)** | Average score $\ge 4.0 / 5.0$ ($80\%+$) | Verifies user-centered interface compliance and low friction for first-time users. |
| **Security & Fairness Index** | $\ge 85\%$ positive sentiment | Validates that position shuffling and answer masking successfully addressed lab anti-peeking concerns. |
| **Incident Rate** | $\le 10\%$ of participants reporting glitches | Proves LAN stability, Socket.io connection resilience, and SQLite WAL concurrency under full lab load. |
| **Traditional vs. Digital Preference** | $\ge 90\%$ rating system "Better" or "Superior" | Establishes the return on investment (ROI) and justification for replacing whiteboard/paper quiz bees. |
